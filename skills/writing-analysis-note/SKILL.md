# Analysis Note (AN / ASN)

## Purpose

The reviewable internal document that describes an analysis (or one
combination of analyses) well enough for the collaboration to judge it.
Basic skeleton only - fill with your experiment's template.

## Preconditions

- Analysis results exist as validated outputs (run dirs + gate reports from
  the harness), not as hopes.
- Know the document's status: draft, for-review, approved, superseded.
- Author list and review chain (conveners/referees) identified.

## Minimal structure

1. **Title page**: number, version, date, authors, status, abstract.
2. **Introduction**: physics motivation, 1 page max.
3. **Detector / dataset**: dataset, luminosity/trigger, MC samples table.
4. **Object selection & reconstruction**: definitions used, not invented.
5. **Event selection**: cuts table with justification for each.
6. **Background estimation**: method per region; control regions defined
   *before* results are shown.
7. **Systematics**: table of sources, evaluation method, size.
8. **Results**: plots with full captions (data vs MC, uncertainties);
   every number in text matches a table/plot exactly.
9. **Summary + bibliography.**

## Rules (harness-style)

- Every number in the text must be generated by a script from the run
  directory; never hand-typed. Quote only membrane-filtered output.
- Blinding: if the signal region is blinded, state it and verify no
  unblinded value leaked into earlier sections.
- Version control: each circulated version tagged; referee comments kept
  with dispositions (resolved / deferred / rejected + why).
- Negative control check: rerun one rejected-background variant and confirm
  the note does not quote it.

## Validation

- Numbers table: text vs table vs plot - all agree.
- All referenced figures exist and are reproducible from run dirs.
- Status line matches reality (do not label "approved" before signatures).

## Failure recovery

| symptom | remedy |
|---|---|
| number mismatch text vs plot | regenerate both from the same run dir; never edit the text by hand |
| section missing (referee complaint) | add it from the run dir artifacts; do not backfill from memory |
| result changed after a fix | bump version, list changed numbers in the revision notes |
